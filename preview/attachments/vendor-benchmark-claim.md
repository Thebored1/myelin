# vendor.example — our agent outperforms models 4x our size

Undated vendor page, captured as a document. Reproduced in summary.

> **Not evidence.** No task suite, no scaffold description, no seeds, no reruns. This is a marketing claim captured for reference and is not used to support any claim in the paper.

## The claim

vendor.example reports that its deployed agent outperforms models approximately four times its size on internal tool-use workloads.

The page gives a single figure — a 4x class ratio — and presents it as a property of the agent rather than of the agent-plus-configuration it was measured in.

## What is not provided

| Item | Status |
| --- | --- |
| Task suite | Not published. Described as internal. |
| Scaffold description | Not provided. |
| Seeds or repetitions | Not provided. Single figure. |
| Baseline configuration | Not provided. |
| Rerun of competitor models | None. |

The comparison is against a competitor's own published numbers, taken as reported. vendor.example has not run the competitor models, under its scaffold or any other. The ratio therefore conflates three things that were not held fixed: the model, the harness, and the task definition each party used.

## Status

This document is retained only to show what a bare harness-effect claim looks like when nothing is controlled.

It is the same logical shape as the vendors' announcements in the Feb 2026 trade reporting, where each party reports its own configuration as a fixed condition and compares outward against a rival's published figures. A 4x claim of that form cannot be decomposed, and it cannot be checked by a third party.

It is not cited, not corroborated, and not a measurement of anything the paper measures.
